Neon Bay is a 3D open-world action game inspired by GTA 6: a dense living city (2400×1800 m, 3 districts), 60 main missions, drivable cars, boats and planes, a 5-star wanted system, shops, a safe house, day/night and seasons — playable on PC and mobile.

Play it now: https://ayubzoel.github.io/neon-bay/game/

## Run it

```sh
node serve.ts --port 8097
# then open http://localhost:8097/
```
